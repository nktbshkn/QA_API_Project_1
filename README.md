# API тестирование сервиса доставки продуктов

## О проекте

В рамках проекта проводилось тестирование новой функциональности backend API сервиса доставки продуктов.

Основная цель:
- проверить корректность работы новых API-методов;
- протестировать CRUD-операции;
- выявить дефекты перед релизом новой версии API.

Тестирование выполнялось через Postman на тестовом стенде.

---

## Что было протестировано

### Работа с наборами
Проверка ручки:
- POST /api/v1/kits/{id}/products

Проверялось:
- добавление продуктов в набор;
- обработка корректных и некорректных данных;
- граничные значения;
- обработка ошибок.

---

### Работа с курьерской доставкой
Проверка ручки:
- POST /fast-delivery/v3.1.1/calculate-delivery.xml

Проверялось:
- расчёт стоимости доставки;
- проверка доступности доставки;
- обработка XML-запросов;
- корректность ответов API.

---

### Работа с корзиной
Проверка ручек:
- GET /api/v1/orders/:id
- PUT /api/v1/orders/:id
- DELETE /api/v1/orders/:id

Проверялось:
- получение списка товаров;
- добавление товаров в корзину;
- удаление корзины;
- обработка некорректных запросов;
- корректность статус-кодов и ответов API.
